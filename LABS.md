# Лабораторные работы по компьютерной графике (Vulkan), вариант 1 — куб

Все четыре работы собираются из одного CMake-проекта, но каждая — **отдельная программа**
со своим каталогом. Каждая следующая работа начинается с копии кода предыдущей и дополняет его.

| Работа | Каталог | Исполняемый файл | Что добавляется |
|---|---|---|---|
| ЛР №1. Основы 3D-графики | [labs/lab1](labs/lab1) | `lab1.exe` | куб, проекции, трансформации, анимация, цвета вершин |
| ЛР №2. Камера и освещение | [labs/lab2](labs/lab2) | `lab2.exe` | камера, нормали, Блинн-Фонг, 3 типа источников, storage-буферы |
| ЛР №3. Текстурирование | [labs/lab3](labs/lab3) | `lab3.exe` | UV, текстуры, динамический UBO, VRAM, push-константы |
| ЛР №4. Наложение теней | [labs/lab4](labs/lab4) | `lab4.exe` | карта теней через dynamic rendering, тень от прожектора |

Общий каркас (одинаковый для всех работ) лежит в [source/](source):
окно и цикл кадров (`main.cpp`), swapchain и ImGui (`graphics_internal.cpp`, из стартового кода),
вспомогательные функции Vulkan (`vk_utils.cpp`: буферы, staging, текстуры, создание конвейеров).
Единственное отличие каркаса между работами: для ЛР №4 включается Vulkan 1.3 и `dynamicRendering`
(макрос `GRAPHICS_ENABLE_DYNAMIC_RENDERING`, задаётся в `CMakeLists.txt`).

## Сборка и запуск

```bash
cmake --preset msvc-release          # или: cmake -S . -B build -G "Visual Studio 17 2022"
cmake --build build-release --config Release --parallel
build-release/Release/lab1.exe       # lab2.exe, lab3.exe, lab4.exe
```

Шейдеры компилируются `glslc` автоматически при сборке (рядом с исходниками появляются `*.spv`).
Пути к шейдерам и текстурам зашиты при сборке абсолютными, поэтому exe можно запускать из любого каталога.

Текстуры для ЛР №3–4 уже лежат в [assets/textures](assets/textures). Они сгенерированы скриптом
[tools/generate_textures.py](tools/generate_textures.py) (numpy + Pillow), его можно перезапустить.

**Камера (ЛР №2–4):** зажать ПКМ и двигать мышь — поворот; WASD — движение; Q/E — вниз/вверх; Shift — быстрее.

## ЛР №1 — Основы 3D-графики

Файлы: [application.cpp](labs/lab1/application.cpp), [cube.vert](labs/lab1/shaders/cube.vert), [cube.frag](labs/lab1/shaders/cube.frag)

- **Базовое задание:** куб из 8 вершин и 12 треугольников (`createCubeGeometry`), матрицы MVP через GLM.
- **Доп. 1:** переключатель Perspective/Orthographic, FOV, высота области для ортографии, near/far (`projectionMatrix`).
- **Доп. 2:** позиция, поворот (углы Эйлера), масштаб выбранного куба.
- **Доп. 3:** движение по траекториям «окружность», «фигура Лиссажу», «роза» с вращением; кнопка Pause/Play, скорость, радиус, высота, частоты (`trajectoryOffset`).
- **Доп. 4:** `ImGui::ColorEdit3` для цвета фигуры.
- **Доп. 5:** цвет вершины = её локальная позиция, переведённая в RGB; цвет из интерфейса умножается на цвет вершины (в `cube.vert`).
- **Доп. 6:** на сцене несколько кубов (можно добавлять/удалять), у каждого свой uniform-буфер и **свой `VkDescriptorSet`**; при отрисовке меняется только привязанный набор (`addObject`, `render`).

## ЛР №2 — Камера и освещение

Файлы: [application.cpp](labs/lab2/application.cpp), [lit.vert](labs/lab2/shaders/lit.vert), [lit.frag](labs/lab2/shaders/lit.frag), [unlit.*](labs/lab2/shaders)

- **Базовое задание:** свободная камера (позиция, yaw/pitch, FOV), направленный источник (азимут/высота, цвет, интенсивность), ambient, материал (альбедо, цвет блика, коэффициент блеска). У куба 24 вершины с процедурными нормалями. Сцена: пол, стена, несколько кубов.
- **Доп. 1:** набор 0 — сцена (UBO + 2 storage-буфера источников), набор 1 — модель (матрица + материал).
- **Доп. 2:** массив точечных источников в storage-буфере, затухание `1/d²`, добавление/удаление, вращение по орбите.
- **Доп. 3:** массив прожекторов в storage-буфере, затухание `1/d²`, мягкий край между внутренним и внешним углом.
  Размер массивов в шейдере не фиксирован (`PointLight point_lights[]`), буферы растут по мере добавления (`ensureStorageCapacity`).
- **Доп. 4:** яркие кубики цвета источника и белые линии конуса для прожекторов, отдельный неосвещаемый конвейер; галочка «Show light sources».

## ЛР №3 — Текстурирование

Файлы: [application.cpp](labs/lab3/application.cpp), [lit.vert](labs/lab3/shaders/lit.vert), [lit.frag](labs/lab3/shaders/lit.frag)

- **Базовое задание:** у вершин есть UV; изображения загружаются с диска через `stb_image` (PNG и JPEG), копируются в VRAM и для них генерируются mip-уровни (`vkutil::loadTexture`).
  Свойства всех моделей лежат в **одном динамическом uniform-буфере**, сдвиг передаётся в `vkCmdBindDescriptorSets` (dynamic offset).
  Вершинный и индексный буферы перенесены в **VRAM через staging-буфер** (`vkutil::createDeviceBuffer`).
- **Доп. 1:** 6 материалов (ящик, кирпич, плитка, лавовый камень, sci-fi панель, руна), у каждого свой набор дескрипторов; выбор текстуры для каждой модели в выпадающем списке.
- **Доп. 2:** у «Magic cube» одна и та же текстура сэмплируется тремя разными UV (вращение, прокрутка, волна), смешивается и модулируется цветом, всё зависит от времени. Включение — флагом в **push-константах** (`EffectPushConstants`), а не через UBO.
- **Доп. 3:** specular- и emissive-текстуры (emissive у лавы построен на шуме Перлина). Если текстуры у материала нет, подставляется служебная текстура из одного чёрного пикселя: specular × 0 = нет блика, emissive + 0 = нет свечения.

## ЛР №4 — Наложение теней

Файлы: [application.cpp](labs/lab4/application.cpp), [shadow.vert](labs/lab4/shaders/shadow.vert), [lit.frag](labs/lab4/shaders/lit.frag)

- **Базовое задание:**
  - карта теней `D32_SFLOAT` 2048×2048 рисуется каждый кадр через `vkCmdBeginRendering`/`vkCmdEndRendering`, без `VkRenderPass` и `VkFramebuffer` (`recordShadowPass`);
  - отдельный конвейер с единственным вершинным шейдером `shadow.vert`, без фрагментного шейдера;
  - солнце: `glm::ortho` + `glm::lookAt` (`sunViewProjection`);
  - новый `VkSampler` с `compareEnable = VK_TRUE`, `compareOp = VK_COMPARE_OP_LESS` (`createShadowResources`);
  - в `lit.frag` карта читается как `sampler2DShadow`, дополнительно сглаживание PCF 3×3/5×5;
  - в интерфейсе (вкладка Shadows) задаются площадь ортографической проекции, центр, расстояние, near/far, depth bias (константный и по наклону) и показываются сами карты теней.
- **Доп. задание:** выбранный прожектор тоже отбрасывает тень — вторая карта 1024×1024 с перспективной проекцией (`spotViewProjection`), выбор источника в выпадающем списке «Shadow caster».
